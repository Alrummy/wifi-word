Entry for make.fun's “One Word for Your Wi-Fi” bounty. Entrants send a single word describing their Wi-Fi. A judge model compares the words in private pairs and the funniest, truest one wins the reward.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
